# Contributing

Thanks for considering a contribution. This is the default guide for
repositories owned by [oney-erge](https://github.com/oney-erge); a repository's
own `CONTRIBUTING.md` takes precedence where one exists.

## Before you start

- For anything beyond a small fix, open an issue first so we can agree on the
  approach before you spend time on it.
- Read the repository's `README.md` and, if present, `AGENTS.md`. `AGENTS.md`
  describes how the code is organized and the standard changes are held to,
  including AI-assisted ones.

## Making a change

- Keep pull requests small and focused on one change.
- Run the checks the repository's CI runs (see `.github/workflows/`) and say in
  the pull request what you ran.
- Update documentation when behavior changes.
- Never commit secrets, tokens, personal data or generated build output.

## Reporting problems

Use the issue templates. Report security problems privately as described in
[SECURITY.md](SECURITY.md).

By contributing, you agree that your contributions are licensed under the
repository's license.
