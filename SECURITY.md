# Security Policy

This is the default policy for repositories owned by
[oney-erge](https://github.com/oney-erge). A repository's own `SECURITY.md`
takes precedence where one exists.

## Supported versions

Security fixes go to the latest commit on the default branch and, for packages
that publish releases, the latest release. Older versions are not maintained.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability, and do not
post secrets, exploit details, private logs or configuration in public.

Use GitHub's private vulnerability reporting: open the repository's
**Security** tab and choose **Report a vulnerability**. If that option is not
available, contact the owner through the contact method on the
[oney-erge GitHub profile](https://github.com/oney-erge) and ask for a private
channel.

Please include:

- the affected version or commit and your platform;
- minimal steps to reproduce;
- the impact you expect; and
- whether credentials or third-party systems may have been exposed.

You should get a first reply within a week.
